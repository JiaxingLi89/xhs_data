    ## 实采准备与首次登录
    
    需要Python 3.10以上，推荐3.12；默认使用已安装的Google Chrome和有图形界面的Mac用户会话。
    
    ```bash
    python3 scripts/setup_live.py
    .venv/bin/python -m xhs_research doctor
    .venv/bin/python -m xhs_research login
    ```
    
    安装脚本会优先使用当前兼容的Python；如果系统默认版本太旧，会自动查找已安装的Python或Miniconda。只创建项目内的`.venv`，不修改全局环境，安装`requirements-live.txt`固定的依赖，并生成`requirements-resolved.txt`记录完整已解析依赖。以后复现环境可从该文件安装。离线安装可加`--wheels /本地wheel目录`。如果选择配置中的`browser_channel: "chromium"`，需另运行`.venv/bin/python -m playwright install chromium`。
    
    首次登录会打开专用浏览器，请在小红书正常登录界面扫码；短信或验证码也在浏览器中自行完成。程序不自动获取短信、不反复发送验证码。因全局限速，登录检查之间也可能等待2–5分钟，终端会显示等待信息。确认登录后会自动执行本次采集，无需再输入run。
    
    `config.json`中的`母乳喂养`是根据工作目录设置的**初始关键词**，请在首次实采前按研究方案修改。关键词和排序变化会产生新的采样版本，已入队任务继续保留。如果要完全独立的研究样本，使用新的`data_dir`和`export_dir`。
    
    ```bash
    .venv/bin/python -m xhs_research run
    .venv/bin/python -m xhs_research status
    .venv/bin/python -m xhs_research export
    ```
    
    自定义配置放在子命令前：`.venv/bin/python -m xhs_research --config /绝对路径/config.json run`。配置中的数据路径相对于配置文件目录。独立研究建议使用`data/研究二`和`exports/研究二`，保持在已忽略的目录内。
    
    ## 登录与异常恢复
    
    | 状态 | 行为 |
    |---|---|
    | 有效登录态、程序重启 | 复用`data/browser-profile`，从数据库断点继续 |
    | 浏览器已更新Cookie | 每次请求从浏览器读取，不长期缓存旧Cookie |
    | 登录失效 | 先同步已有会话；仍失效则每日最多自动打开一次登录页 |
    | 等待扫码 | 最多等待10分钟；成功后验证服务端登录状态再续采 |
    | 登录等待超时 | 持久化为`auth_waiting`，后续定时任务不反复弹窗；使用`login`主动处理 |
    | 断网、超时、5xx | 不触发登录；保存至少15分钟退避，后续run或下个计划时段再尝试 |
    | 浏览器断开 | 单次运行最多重建一次；原请求的退避、配额仍然有效 |
    | 同一请求连续两次网络失败 | 持久化暂停，需要检查后`resume`；不无限循环 |
    | 验证、403、限流、安全限制 | 全局暂停，重新登录不清除暂停 |
    | 笔记删除 | 标记`unavailable`，不重试；已尝试笔记计入当天上限 |
    | 链接凭证失效 | 标记`needs_link`，下一次有搜索额度时回原搜索来源刷新一次；找不到则留待核对 |
    | 响应结构变化、异常空正文 | 标记`protocol_error`并暂停，不伪装成零条数据 |
    
    429优先使用`Retry-After`，缺失时冷却24小时。页面自身观察到的限制响应保守冷却24小时。冷却到期不会自动解除风控暂停：检查后执行`resume`，再运行`run`或等待下次定时任务。登录等待用`login`处理。
    
    ```bash
    .venv/bin/python -m xhs_research resume
    .venv/bin/python -m xhs_research run
    ```
    
    会话目录和SQLite包含访问凭证，只保存在本地受限目录；不提交到Git，不写入日志或导出。日志只记录受控诊断代码。收到验证码时仍需要人工处理；保存登录状态不保证服务端永久认可会话。
    
    ## 采集预算和试采验收
    
    | 项目 | 试采 | 正式 |
    |---|---:|---:|
    | 每日处理笔记，含续采和失败尝试 | 5 | 10 |
    | 每日受控请求尝试，含登录检查、重试 | 30 | 60 |
    | 每次运行最多处理笔记 | 5 | 5 |
    | 请求间隔 | 120–300秒 | 120–300秒 |
    | 每篇一级评论上限 | 50 | 50 |
    | 搜索页数上限 | 1页/日 | 1页/日 |
    
    以先达到的上限为准。请求在发送前预留配额：即使预留后程序崩溃或签名失败也不退回，以防重启造成超额。因此`business_requests_today`是保守计数，不是成功请求数。`page_requests_today`单独记录可观察的浏览器页面流量，不包含启动监听前的流量，不能将业务额度等同于全部网络请求。
    
    搜索结果先入队，正文与评论串行处理；候选不足20篇时才补充。所有关键词共享预算。最后一页即使`has_more=false`仍会保存其中结果。评论每页与游标在同一事务提交，重复游标会停止并标记不完整。二级回复和媒体下载关闭。
    
    暂停、游标、当天配额、下次请求时间都存入SQLite。请求参数签名在限速等待结束后生成。网络库的内部重试和自动跳转关闭。每日按Asia/Shanghai划分；每次任务最长4小时，跨日结束当前运行。
    
    试采达到50篇后停止，人工核对至少10篇的正文、时间、互动数、评论归属和字段质量，再执行：
    
    ```bash
    .venv/bin/python -m xhs_research promote --reviewed-notes 10
    ```
    
    这是对实际人工核对的记录，程序不会代替内容审核。正式阶段默认目标1500篇完整笔记，允许配置调整；不会自动提高频率。关键词无新结果时可能达不到目标，应根据研究方案更新关键词并保留采样版本。
    
    ## 定时运行
    
    先完成安装和首次登录，再生成并安装用户级launchd任务：
    
    ```bash
    .venv/bin/python -m xhs_research schedule
    .venv/bin/python -m xhs_research schedule --install
    ```
    
    默认北京时间10:00、16:00；要求系统时区和配置一致。计划文件和日志保存在项目`schedule/`中，不复制到系统目录。没有使用`--install`时只生成文件，不激活任务。`--install`会检查依赖；本次实现环境中未激活。
    
    唤醒后若已错过时段15分钟则跳过，已运行时段不重复执行。单进程锁防止手工任务与定时任务同时操作同一浏览器。关机、未登录桌面会话或休眠期间不采集，不承诺全天无人值守。
    
    卸载时使用生成文件中的实际Label（也可从文件名去掉`.plist`获得）：
    
    ```bash
    launchctl bootout "gui/$(id -u)/local.xhs-research.实际后缀"
    ```
    
    ## 输出和研究口径
    
    每次导出生成带时间戳的新目录，包括：
    
    - `notes.csv`：正文、标题、发布时间、互动数、采集状态和停止原因。
    - `comments.csv`：仅一级评论，使用note_id关联笔记。
    - `sources.csv`：关键词、排序、页码、页内位置、搜索会话、发现时间与采样版本。
    - `research.xlsx`：同样内容的三个工作表。
    - `manifest.json`：行数、配置摘要、时间口径、模拟标记及采样限制。
    
    昵称、头像、主页信息、Cookie、链接凭证均不导出。笔记ID和评论ID用于去重与关联，因此导出数据不应被当成完全匿名数据。笔记和评论的发布时间保留平台原值；采集时间为Unix秒。互动数保留平台字符串，避免把“1.2万”等值伪装成精确整数。
    
    CSV为带BOM的UTF-8，可用Excel打开；公式前缀会转义。XLSX使用文本单元格，单元格最多32767字符，完整长文本以CSV为准。`state != complete`的笔记是未完成或需要核对的样本。`comment_cap`表示截断，`exhausted`表示平台当前返回已结束，不代表所有历史评论。
    
    默认综合排序和前50条评论属于平台返回顺序下的方便样本，不是随机抽样；来源信息保留用于研究方法说明。

    def verify_snapshot(root):
        lock_path = root / "upstream.lock.json"
        if not lock_path.is_file():
            return ["缺少 upstream.lock.json。"]
        try:
            lock = json.loads(lock_path.read_text(encoding="utf-8"))
            issues = []
            for filename, expected in lock["local_sha256"].items():
                path = root / filename
                if not path.is_file() or hashlib.sha256(path.read_bytes()).hexdigest() != expected:
                    issues.append("适配器快照已变化：" + filename)
            return issues
        except (OSError, KeyError, ValueError):
            return ["上游快照记录无效。"]

    async def collect(config, store, command, scheduled=False):
        clock = Clock()
        gate = RequestGate(store, config, clock)
        adapter = MediaCrawlerAdapter(config, store, clock)
        session = SessionManager(adapter, gate, store, config, clock, notify)
        engine = Engine(config, store, session, clock)
        try:
            if store.get("synthetic_demo"):
                raise SetupError("模拟数据库不能用于实采，请使用独立的 data_dir。")
            if command == "run":
                engine.preflight()
            if scheduled:
                scheduled_slot(clock.now(), config, store)
            if command == "login":
                await session.ensure_ready(manual=True)
                await engine.run(already_ready=True)
            else:
                await engine.run()
        except StopRun as exc:
            print("任务已保存：" + str(exc))
        except RiskBlocked as exc:
            store.pause(clock.now(), str(exc), clock.now() + exc.cooldown)
            notify("采集已暂停：" + str(exc) + "。请检查账号，冷却结束后使用 resume。")
        except NetworkFailure:
            store.set("network_until", max(store.get("network_until", 0), clock.now() + config.network_retry_seconds))
            print("网络或浏览器连接中断，已保存进度；不会因此重复触发登录。")
        except ProtocolError:
            store.pause(clock.now(), "protocol_error")
            print("响应结构与预期不符，已暂停；请检查适配器，未将异常响应计为成功样本。")
        finally:
            await session.close()

    def identifier(value):
        if not isinstance(value, str) or not re.fullmatch(r"[A-Za-z0-9_-]{1,128}", value):
            raise ProtocolError("invalid_identifier")
        return value
    
    
    def flag(data, key):
        value = data.get(key)
        if type(value) is not bool:
            raise ProtocolError("missing_pagination_flag")
        return value
    
    
    def search_page(data):
        if not isinstance(data, dict) or not isinstance(data.get("items"), list):
            raise ProtocolError("missing_search_items")
        has_more = flag(data, "has_more")
        items = []
        for row in data["items"]:
            if not isinstance(row, dict):
                raise ProtocolError("invalid_search_item")
            if row.get("model_type") in {"rec_query", "hot_query", "user", "query"}:
                continue
            note_id = identifier(row.get("id"))
            token = row.get("xsec_token")
            if not isinstance(token, str) or not token:
                raise ProtocolError("missing_note_link_token")
            items.append({"id": note_id, "token": token, "source": row.get("xsec_source") or "pc_search"})
        return items, has_more
    
    
    def note_detail(data, expected_id):
        if not isinstance(data, dict) or not isinstance(data.get("items"), list) or not data["items"]:
            raise ProtocolError("empty_detail_response")
        first = data["items"][0]
        card = first.get("note_card") if isinstance(first, dict) else None
        if not isinstance(card, dict):
            raise ProtocolError("missing_note_card")
        actual = card.get("note_id") or first.get("id")
        if actual and str(actual) != expected_id:
            raise ProtocolError("detail_id_mismatch")
        title, desc = card.get("title", ""), card.get("desc", "")
        if not isinstance(title, str) or not isinstance(desc, str) or not (title or desc):
            raise ProtocolError("empty_note_text")
        counts = card.get("interact_info", {})
        if not isinstance(counts, dict):
            raise ProtocolError("invalid_interactions")
        return {"title": title, "text": desc, "type": card.get("type", ""),
                "published_at": card.get("time", ""),
                "tags": [t["name"] for t in card.get("tag_list", []) if isinstance(t, dict) and isinstance(t.get("name"), str)],
                **{name: str(counts.get(name, "")) for name in ["liked_count", "collected_count", "comment_count", "share_count"]}}
    
    
    def comments_page(data, expected_id):
        if not isinstance(data, dict) or not isinstance(data.get("comments"), list):
            raise ProtocolError("missing_comments")
        has_more = flag(data, "has_more")
        cursor = data.get("cursor", "")
        if not isinstance(cursor, str):
            raise ProtocolError("invalid_comment_cursor")
        comments = []
        for row in data["comments"]:
            if not isinstance(row, dict) or not isinstance(row.get("content"), str):
                raise ProtocolError("invalid_comment")
            if row.get("note_id") and row["note_id"] != expected_id:
                raise ProtocolError("comment_note_mismatch")
            comments.append({"id": identifier(row.get("id")), "content": row["content"],
                             "time": row.get("create_time", ""), "like_count": row.get("like_count", "")})
        return comments, cursor, has_more
    
    
    def authenticated(data):
        if not isinstance(data, dict) or not isinstance(data.get("result"), dict):
            raise ProtocolError("unknown_auth_response")
        success = data["result"].get("success")
        if success is False:
            raise AuthExpired("not_logged_in")
        if success is not True:
            raise ProtocolError("unknown_auth_response")
        return True
